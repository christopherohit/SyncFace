================================================================================
USAGE FLOW
================================================================================

1. [Optional] Preprocess geometry:
   python preprocess_geometry.py --data /path/to/person

2. Pre-train UMF (Phase 1):
   python pretrain_umf.py --data_root /path/to/multi_person --workspace pretrain

3. Adapt to new identity (Phase 2):
   python adapt_identity.py --umf_checkpoint pretrain/umf_final.pth \
       --data /path/to/new_person --workspace adapt

4. Test implementation:
   python tests/test_instag_modules.py
   python tests/test_training_sanity.py

================================================================================
INTEGRATION WITH SYNCTALK
================================================================================

The implementation extends SyncTalk without modifying original files:

- Inherits from NeRFRenderer for rendering pipeline
- Reuses AudioNet and dataset infrastructure
- Adds new modules in separate files
- Provides alternative training scripts
- Can coexist with original SyncTalk

To use:
- Original SyncTalk: python main.py [args]
- InsTaG pre-train:  python pretrain_umf.py [args]
- InsTaG adapt:      python adapt_identity.py [args]


================================================================================
CONDA ENVIRONMENT
================================================================================

Environment name: synctalk

All scripts use:
  conda activate synctalk && python [script.py] [args]

Dependencies (same as original SyncTalk):
  - torch
  - numpy
  - opencv-python
  - Custom CUDA extensions (gridencoder, raymarching, etc.)

Optional (for geometry preprocessing):
  - timm (for MiDaS)
